Vesuvius Challenge — Villa

Three optimizations developed in a fork for the patch cache writer, 3D ink planning and sparse OME-Zarr pyramid generation. These are operation-level benchmarks.

The planning output matched exactly. Six pyramid levels and the cache JSON matched byte for byte in their respective benchmarks. One bounded trained CPU check also matched across four configurations.
